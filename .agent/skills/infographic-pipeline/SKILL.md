# 教學圖卡標準生成管線 (Infographic Pipeline)

本 Skill 定義本專案專屬的工作流程標準，所有參與的 Agent 請嚴格按照以下階段推進。

## 執行流程守則

### 階段一：筆記草稿撰寫與審查 (`notes/`)
- 知識點濃縮，劃分【核心圖卡區】與【延伸補充區】。
- 檢驗 LaTeX 公式在 KaTeX 下的語法相容性。
- **必須停下由使用者確認內容無誤**。

### 階段二：單頁 HTML 圖卡排版 (`html/`)
- 嚴格維持 A4 直式比例（寬度固定，高度受限，不溢出單頁）。
- 捨棄無實質意義的花俏插圖，採用純 CSS、SVG 或 JS 解說圖表。
- **必須停下由使用者確認網頁版面與視覺階層**。

### 階段三：高解析度 PNG 圖卡輸出 (`png/`)
- 運用自動化無頭截圖引擎輸出 Retina 高畫質 A4 PNG。
- **由使用者檢視圖檔品質**。

### 階段四：版本控管與推送 (`git / GitHub Desktop`)
- 執行自動化推送或指引使用者透過 GitHub Desktop 同步。
