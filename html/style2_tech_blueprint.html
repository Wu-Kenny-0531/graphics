Agent-Based Model (ABM)

分散式微觀決策 × 宏觀複雜性湧現
捨棄宏觀預設公式，透過定義異質主體 (Autonomous Agents) 在空間與網絡中的局域互動法則，自下而上湧現系統階層的動態秩序。
01 / 三大核心架構支柱 (Architectural Triad)
[CORE_PRIMITIVES]
COMPONENT 01

主體 (Agents)

具備狀態記憶、自主決策、異質性特質與有限理性，對局域刺激產生非線性反應。

COMPONENT 02

環境 (Environment)

提供主體運行的拓撲載體（如 2D 離散格網、動態社交網絡圖、連續空間場域）。

COMPONENT 03

規則庫 (Interaction Rules)

定義感知邊界、條件反饋與學習適應算法，驅動系統狀態轉移。

02 / 微觀狀態轉移與宏觀觀測算子
MICRO TRANSITION FUNCTION $$s_i(t+1) = f\Big(s_i(t), \; \mathcal{N}_i(t), \; E(t)\Big)$$
MACRO EMERGENCE OBSERVABLE $$M(t) = \mathcal{G}\Big(\{s_i(t)\}_{i=1}^N\Big) \approx \frac{1}{N}\sum_{i=1}^N g(s_i(t))$$
03 / 建模典範比較：微分方程 (Top-Down) vs ABM (Bottom-Up)
[BENCHMARK]
比較維度 傳統頂層模型 (ODE / PDE) 代理人基礎模型 (ABM)
建模視角 頂層宏觀聚合，方程式直接約束群體總量 底層微觀個體，從個體行為互動湧現宏觀趨勢
個體假設 均質假設 (Homogeneous)，平均場代表性主體 完全異質 (Heterogeneous)，允許差異化策略與資源
互動拓撲 假設全混態 (Well-mixed)，忽略局部拓撲空間 基於網絡圖與局部鄰域，支援關鍵樞紐節點演化
04 / 經典驗證範例 (Benchmark Milestones)
謝林隔離模型 (Schelling)

微弱同族偏好即觸發宏觀極端隔離，揭示個體意圖與群體結果之非線性斷層。

Boids 鳥群模擬 (Reynolds)

避碰、對齊、聚合三條局部演算法，無中央控制即可生成擬真鳥群協同飛行。

複雜網絡傳播 (SIR on Networks)

模擬異質社交網絡中的病毒傳遞路徑，量化超級傳播者之臨界影響。
